# Bailgadi

A small browser-based 3D bullock-cart game set on a low-poly Indian village
road. Built with Vite, vanilla JavaScript, and Three.js.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Controls

- `W` / `ArrowUp` — accelerate
- `S` / `ArrowDown` — brake and reverse
- `A` / `ArrowLeft` — steer left
- `D` / `ArrowRight` — steer right

Touch controls appear automatically on small screens and touch devices.

## Production build

```bash
npm run build
```
