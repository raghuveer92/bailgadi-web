# Bailgadi audio placeholders

The audio manager looks for these optional files:

- `village-ambience.mp3`
- `bull-hoofstep.mp3`
- `cart-wheels.mp3`
- `cart-creak.mp3`
- `bull-bell.mp3`
- `driver-chal.mp3`
- `driver-ruk.mp3`

Missing files are handled silently and never block gameplay. Add appropriately
licensed, optimized audio at these paths when final sound assets are available.
